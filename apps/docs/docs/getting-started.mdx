# Getting Started

These docs describe **PUDA CLI v0.2.0**, in beta: CLI **v0.2.0-rc1** and Python SDK **0.1.0rc1**, which speak PUDA Edge Protocol 1.0. For the current stable release, pick **v0.1.x** in the version dropdown. See the [v0.2.0-rc1 release notes](https://github.com/PUDAP/puda/releases/tag/v0.2.0-rc1).

If you are running **0.1.x**, follow [Upgrading to v0.2.x](./upgrading-to-0.2.x). If you are still on **0.0.x**, follow [Upgrading to v0.1.x](./upgrading-to-0.1.x) first.

PUDA is a hardware harness for Physical AI. Read more about it at [puda.co/blog/paper](https://www.puda.co/blog/paper).

## What You Will Need

Some experience with Linux and Docker, plus hosts for the AI agent, NATS server, and any machine edge services.

See [Hardware Requirements](./setup/hardware-requirements) for recommended minimums.

Keep every edge, driver, Docker service, configuration, and skill for a deployment in one [deployment monorepo](./setup/deployment-monorepo), even when they run on different machines.
